你好，我想委托一套 Live2D 模型。先把项目背景、需求范围和几处特殊要求说清楚，方便你判断能不能接、以及大概报价。

## 一、这是什么项目

我在做一个**个人自用**的 Windows 桌面宠物小软件：昔涟会待在桌面上（透明、无边框、置顶），根据程序的状态切换表情和动作——待机、思考、任务完成、出错等等。

- **使用者只有我自己**（可以的话我会把成品**免费**公开给人用，这一点后面第十一节想跟你确认）
- 角色是《崩坏：星穹铁道》的昔涟，属于**同人二创**
- 软件里角色**显示尺寸很小，高度约 250 像素**

## 二、⚠️ 先说重点：我要的不是主播皮套

这一条最要紧。市面上大部分 Live2D 是给主播做皮套的，用途和我的差别不小，有几处需要你特别留意：

| | 常见的主播皮套 | **我需要的** |
|---|---|---|
| 怎么驱动 | 摄像头**实时面捕** | **程序事件**驱动（我在代码里按参数名、动作名调用） |
| 身体范围 | ⚠️ 通常**只做上半身**（摄像头拍不到腿） | **完整坐姿，腿和高跟鞋都要** |
| 姿态 | 站姿 / 半身 | **坐姿**，不需要走动 |
| 交付配套 | VTube Studio / VSeeFace 配置、键位映射 | ❌ **不需要**，我不用那些软件 |
| 纹理尺寸 | 4K / 8K | **2048 足够**（显示只有 250px 高） |
| 换装 | 常配好几套衣服 | 只要一套 |
| 表情怎么切 | 按 hotkey 一下一个 | **程序按状态切换**，需要能叠加、能中断 |
| 待机 | 靠面捕的微动 | **完全自己动**（没有外部输入时也要呼吸、眨眼、微动） |

**所以有三件事想提前拜托你：**

1. **腿和脚请一起做**（完整的坐姿），不要只做上半身。
2. **不用做 VTube Studio / VSeeFace 的配置文件，也不用键位映射**——这两块省下来。
3. **待机动作要能自己持续循环**，「思考」这类动作要能循环好几分钟，而且切换到别的动作时**前一个要能被立刻打断**。

## 四、⚠️ 需要你做的两部分工作

Live2D 通常是两个环节，**请告诉我你接哪一部分**（也可以都接）：

| | 交付物 | 内容 |
|---|---|---|
| **A. 拆件 + 补绘** | **分层 PSD** | 把角色拆成独立部件，并把被遮挡的部分**补画完整** |
| **B. 绑定** | **`.moc3` 模型** | 在 Cubism 里做网格、参数、物理、动作和表情，导出运行时文件 |

> 如果你只接 A 不接 B，请直接说 —— 一份 PSD 我这边用不了，需要再找绑定师。
> 如果你平时只画插画、没做过 Live2D 拆件，也请直接说，不用勉强。**Live2D 的分层和普通插画的要求正好相反**：被遮住的地方必须补画出来，这在插画里是白费工夫，在 Live2D 里是必需的。

## 五、角色设定（请务必沿用）

1. **基准姿势是 `idle-open`**。
   另外 5 张的姿势、构图和尺寸都不一样，**只作参考**，不要拿来当分层基准。

2. **请不要重新设计角色。**
   现有 6 张图是反复修改后定下来的，尤其是：
   - **鞋子必须是高跟鞋**（不是露趾凉鞋）
   - 足部和腿的比例以现有图为准
   - 发饰、头饰、服装配色都不要改
   如果你觉得现有图有明显问题，先跟我说，我们一起确认再改。

3. **透明背景**。不要背景、不要地面阴影、不要环境光效。
   `success-wave` 里那些星星闪光请**单独分层**，不要合进角色里。

4. **画布建议 1000 × 1500 像素**（和现有素材一致）。
   角色在软件里只有 250px 左右高，所以**线条不要太细**，细节要经得起缩小。

5. **裙子那层半透明的纱请单独成层。**

## 七、⚠️ 需要补绘的地方（这次委托的主要工作量）

以 `idle-open` 的坐姿为基准，下面这些位置需要**补画成完整形状**（即使最后被遮住）：

- 被刘海遮住的**额头**
- 被头发遮住的**肩膀、后背、脖子两侧**
- 被手和裙摆遮住的**裙子内侧**
- 被裙摆遮住的**腿**
- 每只手臂**被身体挡住那一侧**的完整形状（抬手挥手时会露出来）
- 被头饰和头发遮住的**头顶**
- 眼睛被睫毛遮住的部分
- 双腿并拢时**两腿互相遮挡**的内侧
- 鞋子被裙摆遮住的部分

这部分工作量不小，**报价时请一并考虑**。

### ⚠️ 关于版本（这条最重要，麻烦先回复）

`.moc3` 是有版本号的文件，**加载它的运行库也有版本，两边必须对得上**，否则模型拿回来程序读不了。

主播皮套一般不会有这个问题（大家用的软件一样），但我这边是**自己选运行库**，所以要先跟你对齐：

1. 你用的是哪个 **Cubism 版本**？

**确认之后我再决定用哪套运行库，然后再开工** —— 这样不会白做。
