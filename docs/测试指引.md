# 昔涟桌宠 · 测试指引（给测试者）

> 谢谢帮忙测试！这份只有一页，读完就能上手。
> 遇到问题请**按最后一节的方式反馈**，那能省掉一半来回。

## 这是什么

一只待在桌面上的**昔涟**（《崩坏：星穹铁道》）。她会跟着 **DSH**（DeepSeek Harness）的状态变化：
你在干活时她摆"思考"姿势并荡秋千，干完活她回到待机，有审批积压会冒泡提醒你。

**她是独立的一个小窗口**（透明、置顶、可拖动），不是 DSH 界面里的东西。
所以：**DSH 最小化了她还在**；鼠标移到她身上才接管点击，移开就穿过去，不挡你干活。

---

## 装（三步）

1. **解压**这个压缩包到任意目录（路径里有中文/空格都没关系）
2. **双击 `安装.cmd`** —— 它会自动检查环境、下载缺的东西、把插件挂进 DSH
   - 首次会下载 Electron（约 100 MB），**要等 1~2 分钟**，窗口别关
   - 想先看看会发生什么：`安装.cmd --dry-run`（只检查，不写任何东西）
   - 装完它会告诉你下一步。**再点一次也没事**（幂等）
3. **重启 DSH**，然后双击 **`start-pet.cmd`** → 她应该出现在桌面上

**前提**：你得装好 DSH，并且**至少启动过一次**。

> ⚠️ **如果她显示成一个占位的小熊/方块，这是正常的** —— 说明这台机器上没有 Live2D 模型文件。
> 请找我要模型（放到 `assets\live2d\Cyrene\`），或者先测功能逻辑也行。
> **这不是 bug，不用报。**

## 怎么用

| 操作 | 效果 |
|---|---|
| **左键点她的脸** | 戴上像素墨镜（2 秒） |
| **左键点头顶**（头饰/头发/背饰） | 舒服得眯起眼 + 轻轻歪头 |
| **左键点两侧的秋千翅膀** | 像被弹了一下 |
| **3 秒内连点秋千 6 次以上** | 出晕（眼睛变圈圈） |
| 左键点她的**身体/裙子/两侧长发** | **没反应**（设计如此，不是坏了） |
| **按住拖动** | 挪动位置，松手有秋千余摆 + 眨眼 |
| **右键她** | 弹出操作面板（派活/打断/看用量） |
| 点空白处 | 穿透过去，正常点到桌面/其他窗口 |
| **`Ctrl + Shift + Q`** | **退出桌宠**（她没有关闭按钮，也不在任务栏里） |

## 请重点测这些

1. **状态跟随**：让我在 DSH 里干一段活 → 她应该进"荡秋千 + 手放下巴"；干完 → 回待机
2. **点击互动**：上面表格里每一项都点一遍，尤其**点头顶**和**连点出晕**
3. **点击穿透**：把鼠标移到她**旁边的空白**，点一下 —— 应该点到桌面上，而不是被她挡住
4. **拖拽**：拖到屏幕不同位置，松手后位置**下次启动还记得**
5. **右键面板**：派一条无害的活（比如"回个 1"），看能不能发出去、能不能打断
6. **挂机**：就这么放着跑一两个小时，看有没有卡死、变慢、窗口错位

## 已知问题（**这些不用报**）

| 现象 | 说明 |
|---|---|
| 显示成占位形象 | 没有模型文件，正常（见上面） |
| 偶尔点一下没反应 | 已知缺陷：约 **9.5%** 的按下会被吞（边缘处），正在修 |
| 审批来了但 DSH 界面不弹提示 | 已知：桌宠会先"持着"审批，最长 **60 秒**才交棒给 DSH 界面 |
| 点她身体/两侧长发没反应 | 设计如此 |
| 多显示器 / 高 DPI 缩放 | **完全没测过**，请重点看这里有没有错位 |
| 全屏游戏/全屏视频下的点击穿透 | **没测过** |
| 长时间稳定性 | 没测过（正好请你帮忙看） |

## 出问题了，请给我这三样

1. **你点了哪里、期望什么、实际什么**（一句话就行）
2. **日志文件**：`packages\pet-shell\.state\pet.log`（整个文件发我）
3. 如果是启动就失败：把 `安装.cmd` 窗口里的**全部输出**截图给我

想自己先看一眼环境对不对：

```powershell
# 插件是否在线（ok=true 且 code 有数字 = 正常）
Invoke-RestMethod http://127.0.0.1:19387/xilian-pet/health

# 只做环境自检，不开窗
start-pet.cmd --check
```
