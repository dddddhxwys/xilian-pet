昔涟桌宠

贴在 Windows 桌面上的昔涟（Cyrene）：跟着 DSH 的状态冒气泡提示、能拖拽、能派活， 还能替你在桌面上完成审批 —— agent 要执行需要授权的操作时，她自己弹一个小窗，你点「允许」或「拒绝」。

下载哪一个

文件大小什么时候用
slim-model约 1.8 MB 通常选这个。装的时候自动下载 Electron（约 150 MB），需要网络能访问华为云镜像
full-model约 156 MB 上面那个装到一半报「下载失败」时用这个 —— 里面已经含 Electron，不需要下载任何东西

三步装好

  1. 解压到一个新文件夹，路径用纯英文，例如 C:\xilian-pet。
    ⚠️ 不要在压缩包窗口里直接双击里面的文件 —— 那样 Windows 只把那一个文件解到临时目录，必然报错。先「全部解压缩」。
  2. 双击 安装.cmd，等它跑完。
    窗口会先显示一段英文说明，然后一直空着是正常的：所有输出都写进同目录的 install-log.txt，跑完才一次性回显。如果要下 Electron 可能要几分钟，别关窗口。
  3. 重启 DSH，然后双击 start-pet.cmd —— 她就出现了。退出按 Ctrl+Shift+Q。

平时怎么用

操作效果
左键点她 分区互动（部件级判定）：点脸 → 戴墨镜（2 秒自动摘）； 点头顶（头饰 / 头发 / 背饰）→ 摸头反应（舒服得眯起眼 + 轻轻歪头）； 点两侧秋千翅膀 → 弹她一下；3 秒内点秋千超过 5 次 → 出晕
按住拖动换位置，位置会自动记住
右键点她 弹出操作面板（独立小窗）：派活目标、派活 / 打断、本次会话用量、缓存命中、插件连接状态
鼠标移到透明处鼠标穿过去，不挡住下面的窗口
Ctrl+Shift+Q退出

点身体 / 手 / 腿 / 裙摆等没有配区的部件 → 什么都不做（刻意如此：行为可预测、不会误触）。 双击她也不做任何事 —— 面板只有右键这一条路。她会说话的地方是状态气泡（DSH 事件与主动提醒），不是点出来的。

装不上？先看这几条

窗口一直空着那是正常的 —— 输出在 install-log.txt 里，跑完才回显。盯那个文件的大小就知道在不在跑
报 Cannot find module …\Temp\…zip…你在压缩包里双击了文件。先全部解压缩，再从解压出来的文件夹里双击
报「找不到 Node runtime」安装器会打印具体找过哪些位置。先启动一次 DSH 并让它真正干点活（它首次使用时会解包运行时），再重跑安装
插件列表里没有卡片 / /health 报 404① 没重启 DSH；② 安装器走了「免安装直挂」模式（能用，但列表里不显示）。重跑 安装.cmd 或手动用 DSH 的 CLI 装
审批没走桌宠看 http://127.0.0.1:19387/xilian-pet/health：code 应是 27、approvalViaPet 应是 true、subscribers 应 ≥ 1（她没连上时审批按设计立刻交给 DSH 界面）
她说自己退出了 / 状态不动subscribers 是 0 就说明外壳没连上，重新双击 start-pet.cmd
